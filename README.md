# Terraform Architecture Playground

This repository is a collection of cloud infrastructure architectures
implemented using Terraform. Each folder represents a standalone
architecture or design pattern, focusing on best practices around
security, scalability, and maintainability.

## Architectures

- [Static Website Hosting with S3 and CloudFront](./static-website-cloudfront-s3)
- [VPC with Public and Private Subnets](./vpc-public-private)
- ....

## How to Use

Each architecture folder contains:
- A dedicated README explaining the design
- Terraform configuration files
- Clear separation of concerns and variables

Architectures are intentionally kept independent so they can be
applied, modified, or destroyed in isolation.

## Notes

This repository is intended as a playground for experimenting with
cloud architecture patterns using Terraform. It may evolve over time
with new designs and refinements.
